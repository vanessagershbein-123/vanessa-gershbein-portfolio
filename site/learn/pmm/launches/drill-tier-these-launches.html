Tier these launches

PMMDrill 4.110 minIntermediate

Skills: Positioning & strategy

The prompt

The facts. Seven real releases from 2026 appear in the changelog of Linear, the project-tracking tool for software teams1:

Date Release What it does
Late May Linear Diffs Review code from an issue with a linked pull request, make follow-up changes with a background coding agent, and ship from inside Linear. On all plans, with guided reviews in beta for Business and Enterprise
Jun 11 Coding sessions An agent writes code in the cloud from inside Linear. On Basic, Business and Enterprise plans, using AI credits
Aug 13 Team initiatives Teams can lead initiatives, and those led by private teams are visible only to their members
Aug 20 Coding sessions: environments, browser use and updated pricing Configurable environments, browser testing by the agent, and a cheaper usage-based pricing model
Sep 3 Priority inbox A Priority tab separates urgent notifications from the rest
Nov 12 Bring your own key Teams can use their own AI provider keys for the coding agent and be billed by the provider directly
Nov 12 A small command-menu improvement Exact-match commands now rank above issues with the same title in the command menu

Your task: You're a PMM at Linear. Assign each release a tier (1, 2 or 3), say in one line what it gets, and name one pair of releases you'd bundle into a single launch moment.

Your earlier answer

Sample answer

Release Tier What it gets
Coding sessions 1 Full launch: a new way to use Linear and a new source of usage revenue. Launch post, demo video, press, sales and success briefing, in-app announcement
Linear Diffs 1, bundled Launch it with coding sessions as one story about doing the whole job from issue to shipped code
Environments and updated pricing 2 A pricing change needs direct notice to every affected customer, plus a sales and support update. The new features ride along
Bring your own key 2 Matters most to larger companies with security and procurement rules. Brief sales and success, and email admins of eligible plans
Priority inbox 2 or 3 An in-app message for existing users and a changelog entry. Tier 2 only if notification overload is a common complaint
Team initiatives 3 Changelog entry, with a note to admins of private teams
Command menu improvement 3 Release notes only

The bundle: Diffs and coding sessions shipped two weeks apart and tell one story, so they make a stronger single moment than two separate announcements.

Why it works

  • It tiers by impact on customers and revenue, not by how big each engineering project was.
  • It treats the pricing change as more than a feature update, because it changes what customers pay.
  • It uses bundling to make the Tier 1 story bigger instead of launching everything loudly.

What interviewers push on

  • "Why isn't the pricing update Tier 1?" It changes the price of an existing feature rather than opening something new. It could become Tier 1 if many customers' bills rise.
  • "Isn't bring your own key a small technical change?" Small to build, but it can unblock deals with security-minded buyers, which is impact.

Practice twist

Linear's sales team says bring your own key is the top request from enterprise prospects this quarter. Does its tier change, and what would you add to the plan?
